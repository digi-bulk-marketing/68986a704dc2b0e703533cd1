# ZTi IP Blast

ZTi IP Blast by ZTi Ai Automation.

## Installation

### Windows
1. Download the latest **`.exe`** installer from the [Releases page](https://github.com/digi-bulk-marketing/68986a704dc2b0e703533cd1/releases/latest).
2. Run the installer and follow the prompts.
3. Launch **ZTi IP Blast** from the Start menu.

## Updates

Download the newest installer from the [Releases page](https://github.com/digi-bulk-marketing/68986a704dc2b0e703533cd1/releases/latest) and reinstall.
